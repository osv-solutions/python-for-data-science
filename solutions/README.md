# Worked solutions

Solutions to the end-of-chapter exercises of *Python for Data Science* by Vamsi Krishna Kandala. Each chapter has three files:

- `chNN_solutions.md`: the worked solutions to read, with explanations, code, outputs and charts (GitHub shows it as a formatted page);
- `chNN_solutions.ipynb`: the same as a notebook, to run cell by cell;
- `chNN_solutions.py`: the code as a plain script.

There is rarely only one correct solution. If your code gets the same result in a different way, it is right.
